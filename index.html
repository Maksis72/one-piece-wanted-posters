One Piece Bounty API (JSON)

No key and no sign-up: the files are served straight from GitHub, so you can use them as a small One Piece API in an app, a Discord bot or a quiz.

  • JSON: https://raw.githubusercontent.com/Maksis72/one-piece-wanted-posters/main/data/characters.json
  • CSV: https://raw.githubusercontent.com/Maksis72/one-piece-wanted-posters/main/data/characters.csv
  • Groups: https://raw.githubusercontent.com/Maksis72/one-piece-wanted-posters/main/data/groups.json

JavaScript, the 10 highest bounties:

const url = 'https://raw.githubusercontent.com/Maksis72/one-piece-wanted-posters/main/data/characters.json'
const { characters } = await (await fetch(url)).json()
const top = characters
  .filter((c) => c.bounty_known)
  .sort((a, b) => b.bounty - a.bounty)
  .slice(0, 10)

Python, the Straw Hats:

import csv, io, urllib.request
url = "https://raw.githubusercontent.com/Maksis72/one-piece-wanted-posters/main/data/characters.csv"
rows = csv.DictReader(io.StringIO(urllib.request.urlopen(url).read().decode("utf-8")))
straw_hats = [r for r in rows if "straw-hats" in r["groups"].split("|")]

Each character has slug, name, bounty (in Berries, null when unknown), groups, names and nicknames in 7 languages, popularity_rank and a link to its poster. All fields are described in the README.
